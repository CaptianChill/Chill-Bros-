# Tech Assist consolidation audit

This branch consolidates training, equipment knowledge, and 3D technician exercises into the Tech Assist workspace; hardens navigation readability; allows technicians to maintain field equipment records; and captures completed jobs as reusable technical knowledge.

Production runtime review also identified two isolated recent errors outside this feature scope: one Blender render proxy abort and one schedule customer-hydration gateway timeout. These are tracked separately so they are not hidden by the UI consolidation work.
